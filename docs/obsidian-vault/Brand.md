## Identity
- **Name**: GharKa ("from home" in Hindi)
- **Tagline**: "Your neighbor's kitchen, one tap away."
- **Personality**: Warm, trustworthy, homely, community-first, simple

## Typography
- **Headings**: Nunito (600, 700, 800)
- **Body**: Inter (400, 500, 600)
- **Accent**: Caveat (400) — very sparingly

## Trust Framework
- App is a CONNECTOR, not a guarantor
- Never say "guaranteed", "verified cook", "delivery", "order now"
- Say "connect", "neighbor cook", "pickup", "request this dish"
- Disclaimers appear at: onboarding, listing footer, order confirmation, about page

## Terminology
| Never Say | Always Say |
|-----------|-----------|
| Seller | Cook |
| Order now | Request this dish |
| Delivery | Pickup |
| Guaranteed | Community-trusted |
| Vendor | Neighbor |
